# ASCIIFY

A ready-to-run ASCII art generator with text, idea, and image modes. No API key required.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Features

- Text to ASCII typography
- Idea to character art with built-in library
- Image to ASCII via browser canvas
- Multiple styles
- Copy, TXT download, and PNG download
- Animated ASCII hero
- Responsive layout
